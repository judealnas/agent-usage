# Provider logos

Bundled for offline provider identification in card headers:

- `openai.svg`: black monoblossom from the [official OpenAI logo pack](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), linked from [OpenAI's brand page](https://openai.com/brand/).
- `claude.svg`: Claude's orange spark from [Anthropic's Claude Platform branding samples](https://platform.claude.com/docs/en/manage-claude/oauth-apps/branding-samples).

Logos remain trademarks of their respective owners. The Claude spark keeps its
official orange color in both light and dark themes. The OpenAI mark follows the
theme's text color.
